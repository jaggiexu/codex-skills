# APP 衍生测试规则

仅将本文件产生的检查归入“衍生用例”。如果需求明确描述相同行为，则可归入核心用例。

## 平台

- 未区分平台时标签为 `APP`，不复制 Android/iOS 两套相同用例。
- 明确平台差异时拆分为 `Android` 和 `iOS`。

## 可选衍生方向

- 权限：首次拒绝、永久拒绝、系统设置恢复授权。
- 网络：断网、弱网、超时、网络切换、请求重试。
- 生命周期：切后台、回前台、进程被杀、页面恢复。
- 交互：快速重复点击、连续返回、手势与系统返回冲突。
- 输入：键盘遮挡、输入法切换、粘贴、emoji、超长文本。
- 安装升级：首次安装、覆盖升级、版本兼容和数据保留。
- 设备：不同屏幕尺寸、横竖屏、安全区域和系统字号。

不得编造具体提示语、时长、次数、权限策略或兼容版本。需求未说明预期时写入待确认。
