# 输入规则

## 一次调用的边界

同一条调用消息中的全部材料属于同一个需求，无论包含多少文件或图片。一次调用只生成一个 XMind。

## 支持来源

- 图片：PNG、JPG、JPEG、WEBP、GIF、BMP、SVG；读取可见文案、控件、状态、流程箭头和表格。
- 文本：Markdown、TXT。
- 文档：DOCX、PDF；提取正文、表格、图片和页码来源。
- 表格：XLSX、XLS、CSV、TSV；读取相关工作表、表头、规则和枚举。
- 文件夹：递归清点支持的材料，忽略隐藏文件、缓存、输出目录和记忆目录。
- 网页：使用当前已登录浏览器读取可访问页面；失败时停止并说明需要用户上传或导出。
- 设计稿链接：优先读取已登录页面；无法稳定读取时要求导出 PDF 或图片。

## 证据规则

记录每个需求点的来源文件、页码、工作表或 URL。截图中明确可见的元素与文案可作为核心依据；不可见的后台逻辑不得推断为核心需求。材料冲突时保留冲突并标记待确认，不擅自选择一方。
